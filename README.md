# Plants vs. Zombies: Battle for Neighborville - Nextendo server

Nextendo Network server for Plants vs. Zombies: Battle for Neighborville (Blaze protocol), written in Go.

## Build

Run `go build .`; it has no external dependencies. Configuration comes from environment variables; secrets are never stored in this repository.

## Disclaimer

This server ships **no** Nintendo code, keys, or copyrighted assets. It is an independent
reimplementation for use with a community-run replacement service, not affiliated with, endorsed by,
or associated with Nintendo or the game's publisher.
